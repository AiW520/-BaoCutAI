# OpenFox modified edition

This is **开胡-OpenFox (OpenFox)**, a modified edition of BaoCut, based on
AiW520/-BaoCutAI commit `6d9be8e` and the BaoCut project by Jim Liu and contributors.
It is not an official BaoCut release and does not imply upstream endorsement.

Changes include OpenFox branding, a local download page, independent desktop
package identification, and a Windows candidate build workflow.

The original LICENSE and THIRD_PARTY_NOTICES.md remain applicable and are
distributed with the application. The OpenFox name does not replace those terms.
Commercial distribution or commercialization of the covered software requires
the separate written authorization described in LICENSE.

Brand art was supplied by the owner of this fork. Icons are crops of the separately supplied OpenFox fox logo;
no new image was generated. The text `openfox.vip` is part of the supplied brand
art and does not indicate that this page has been deployed to that domain.

Candidate packages have build number zero and do not check upstream update feeds.
The Windows package installs separately as OpenFox. Existing runtime environment
variables, project formats and internal package names remain compatible.
