# 代码场景：整镜整段用 Canvas 或 SVG 画

`SKILL.md` 第 5 节「代码画面」的细则。这里的画面不是一段叠在素材上的图形，而是整镜、整段都由代码画：歌曲的逐句画面、讲解动画、角色小剧场。短的下横栏、关键词、大数字、品牌贴片仍按 `motion-graphics` 做。

## 1. 落点

| 用户要的 | 怎么做 |
| --- | --- |
| 可编辑的视频（默认） | 写成代码包，用 compositions_import 导入。用 `baocut/1` 合同：`initialize` 里等图片与字体加载完（`img.decode()`），`renderAt(time)` 在一块 `<canvas>` 上画出那一刻；全画幅不透明的在根元素写 `data-alpha="false"`。按段落（一段一个场景）切成几个代码包首尾相接，改一段只重新导入那一段（`replace: { itemId }`） |
| 只要一个视频文件，明说由代码直接渲染、不要可编辑视频 | 在 BaoCut 之外渲染，例如逐帧画好交给 ffmpeg 编码。交付时说明画面不能在编辑器里逐个元素改；之后要可编辑，按上一行重做，不把渲染出的文件当素材导入后再叠加修改 |

包内只用相对路径，不联网；上限是 4096 个文件、单个 64 MiB、合计 256 MiB，底图用 JPEG，贴图用 PNG。

## 2. 时间从文稿来

- documents_read 读转写（已按原文写回的那份），把每句的起止时间与文字写成包里的一个数据文件（例如 `lines.js`），画面按它排：每句一个画面窗口。段落（主歌、副歌、间奏）的边界也写进去，用来换场景。
- 一句的画面不越过所在段落的结尾：前一段的最后一句不能拖进下一段的间奏或高潮。
- 没有字的段落（前奏、间奏、尾奏）靠音乐的起伏撑：有命令行环境时，先把音频的响度包络算成数据文件（每帧一个值），让光、缩放、闪烁跟着拍子动。

## 3. 确定性

- 第 t 秒的画面只由 t 决定：不用 `Math.random`、`Date.now` 与自走的动画；要随机就用按编号取值的哈希（同一个编号永远是同一个值）。计数、位置、已出现的元素都从 t 算出来，不逐帧累加。
- 导入时会核对同一时刻两次取帧一致（不一致报 `COMPOSITION_NONDETERMINISTIC`）。确定的画面也能单独取任意一帧、分段并行渲染。

## 4. 画面元素

- **角色、道具与场景底图**：用 `skills_read` 读 `baocut-catalog-media`，按它「生成图片」里「成套素材」的做法画出来、抠好，放进包里。
- **图标、光效、边框**：用代码画。SVG 字符串转成图片画到 canvas 上，或直接用 canvas 路径。矢量图标的动效（火苗、摇铃、闪光）给一个相位参数，按时间取值；转成的图片按尺寸与相位缓存，不每帧重新解码。
- **不用系统 emoji**：各平台的字形不同，离屏渲染时可能没有彩色 emoji 字体。字体也带进包里，画之前确认成片语言的每个字都有字形：缺字会落到别的字体上，例如 `♥` 会被画成彩色 emoji。
- **角色动画**：在几个姿势之间切换，加上位移、旋转、挤压与抖动；不逐帧生成。
- **场景底图**：铺满裁切、慢慢推拉、压暗；字幕所在的那一条保持暗、干净。

## 5. 字幕、封面与署名

- 歌词与字幕默认是字幕层（可改、可双语），画面里只放梗与图，不把同一句话再画一遍。要逐字高亮这类字幕层做不到的样式时才画进代码，这时停用对应的字幕层，不让两份叠在一起。
- **第一帧就是封面**（主 skill 的通用规则）：代码场景里就是 0 秒已把标题与主视觉画完整，不从空白淡入、不弹出，停一两秒再转进正片；用 compositions_preview 取 0 秒核对。
- **片尾署名**：名字、账号与各项分工逐字照用户给的，不改写、不补；你另加的说明（例如「非官方二创」）单独一行。

## 6. 自检

- 先画一帧风格样张给用户看，定下再写全片。
- compositions_preview 一次最多取 24 个时刻：每句、每个段落交界各取一帧拼起来看。查文字重叠、画面空、上一句残留到下一段、元素出画。改完只重看改到的时刻。
- 导入后导出几段预览，听画面跟不跟拍。
- 在 BaoCut 之外渲染时：分段渲染、能续跑；渲染中途不改代码，否则前后段不一致；从成片里抽几帧与单帧渲染比对，核对每段的帧数。
