# Tuzi API 双路径引导验证

验证日期：2026-10-24。基于 `AiW520/-BaoCutAI` 的 `main` 提交 `d613f43e`，保留该仓库已有的 OpenFox 外壳与发布改动。以下在线结果仅代表当次账号与路由状态，不是对整个模型目录的兼容承诺。

## 实现与验证范围

桌面引导先选择 Tuzi API 或本机模型。本机路线沿用六步下载与下载确认；API 路线经同一个 Runtime、Provider 凭据存储、生成任务和用量记录执行，不在渲染进程直接调用服务商。Web 不显示首次引导，也不开放配置写入。

API 路线先用只读请求验证账号，再获取真实模型 ID。`ProviderRefreshStatus.modelIds?: string[]` 是可选的发现结果字段；它与数量一起由存储里的发现列表派生，不含密钥、不推断模型能力。目录失败或为空不会进入能力页；重取目录不重复添加账号。已有同地址端点保留模型声明；同名但地址不同的端点使用新 ID。新增端点验证失败不落盘。

能力页可从账号返回的 ID 中选择模型，明确告知真实测试可能计费。只测试用户选中的文本、图片、语音合成能力，任务失败保留错误原因。只有测试成功且仍被选择的模型可在继续时设为默认。语音识别的逐词时间与说话人需要单独的视频测试，在本引导中不设为默认。音色克隆、音乐、语义索引与参考图编辑不属于已验证能力。
